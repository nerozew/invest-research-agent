# 项目边界

- 这是一个面向学习和作品集、采用生产级工程思想设计的自动化投研系统。MVP 只覆盖能够通过 SEC EDGAR 识别的美国上市公司。
- 做出架构决策前，必须阅读 `README.md` 以及 `docs/01` 到 `docs/05` 的设计文档。
- MVP 只包含三个核心 CrewAI Agent，并且必须按以下顺序执行：信息搜集、财报分析、报告撰写。
- CrewAI Crew 负责 Agent 之间的任务协作；CrewAI Flow 负责状态管理、条件分支、失败恢复和确定性质量门禁。
- LLM 不得负责权威性的财务算术计算。所有财务计算必须通过带版本号的确定性 Python 工具完成，并使用 `Decimal` 处理数值。
- PostgreSQL 是任务和业务状态的唯一可信数据源。Redis 只用于任务队列、锁、限流和缓存。
- 原始文件和大文件应保存到工件存储；数据库只保存元数据、结构化事实、URI 和 checksum。
- 最终报告中的每一项外部事实和关键数字，都必须能够追溯到来源、财务事实或指标公式。
- 产品不得提供个性化投资建议、买入/卖出建议、目标价格或确定性收益承诺。
- 在真正执行文档规定的基准测试之前，不得声称任务成功率已经大于 95%，也不得声称效率提升了 XX%。
