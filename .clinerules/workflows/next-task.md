# 执行下一个路线任务

每次只能执行用户从 `docs/05-DEVELOPMENT-ROADMAP.md` 中指定的一个任务。

1. 阅读当前任务所在行、它的前置条件、相关设计文档以及所有启用的 Cline 规则。
2. 检查当前工作区和已有 diff，不得覆盖或破坏现有工作。
3. 在 Plan 模式中说明：唯一的任务 ID、任务范围、明确不做的内容、可能修改的文件、测试计划和学习目标。如果任务需要继续拆分，或者存在必须由用户决定的产品问题，应停止并等待用户确认。
4. 进入 Act 模式后，只实现当前任务及其测试。除非任务明确要求调用真实服务，否则外部服务必须使用 mock。
5. 运行相关测试、lint 和类型检查。任意相关检查失败时，都不得把任务标记为完成。
6. 只有全部验收条件真正通过后，才能在开发路线中给当前任务 ID 添加 `✅`。如果检查失败或没有执行，必须保持未完成状态。
7. 按学习模式规定的格式汇报结果，然后停止。可以建议下一个任务，但不得直接开始执行。
