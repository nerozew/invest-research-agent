# SEC 财报数据是怎么来的（零基础版）

> 写给完全不懂金融和技术术语的人。用生活类比讲清楚：XBRL 是什么、SEC 有什么查询工具、
> 我们为什么取不到某些数据、网页搜索又是干嘛的。

---

## 0. 一句话结论

**公司的财报数字，在 SEC 那里有一套"贴标签"的存档系统（XBRL）。我们有几个查询工具去取数，
但有的标签公司没贴、有的标签我们用的工具没收全，所以个别数字取不到。**
取不到的时候，我们就用数学公式推导，实在不行才去网上找文字版财报。

---

## 1. 先认识三个"角色"

| 角色 | 是什么 | 打个比方 |
|---|---|---|
| **公司**（如亚马逊 AMZN） | 上市公司 | 交作业的学生 |
| **SEC**（美国证监会） | 监管机构，要求公司交财报 | 收作业的老师 / 档案馆管理员 |
| **我们**（投研系统） | 想从财报里取数字 | 想查资料的学生 |

**流程**：公司把财报（资产负债表、利润表、现金流量表）交给 SEC → SEC 存档公开 → 我们去看。

---

## 2. XBRL 是什么？—— "给财报数字贴标签"

公司交财报时，不是只交一张图，而是**每个数字旁边贴一个"标签"**，告诉电脑"这个数是什么"。

- "637,959" 这个数 → 贴个标签 `收入`（专业叫法：Revenue）
- "326,288" 这个数 → 贴个标签 `销售成本`（专业叫法：CostOfGoodsAndServicesSold）
- "285,970" 这个数 → 贴个标签 `股东权益`（StockholdersEquity）

**XBRL 就是这套"贴标签"的规则系统**。它规定：标签长什么样、叫什么名字、怎么组织。

> 专业点说：XBRL = eXtensible Business Reporting Language（可扩展商业报告语言）。
> 你可以把它想成"财报的条形码标准"——每个数字有条形码，机器能扫。

**为什么贴标签？** 因为电脑读得懂标签，才能自动计算、比较。没有标签，电脑看到的只是"一堆数字，不知道是啥"。

---

## 3. SEC 的"四个查询工具"（接口）

SEC 收了公司的贴标签财报后，提供了几个工具让我们查。就像档案馆有几个窗口：

| # | 工具（接口） | 功能 | 打个比方 |
|---|---|---|---|
| ① | **Company Facts API** | 查**一家公司**的**所有标签**（我们正在用的） | 查一个学生**全部作业**的窗口 |
| ② | **Company Concepts API** | 查**一个标签**的所有历史数据 | 查一个学生**某门课**的全部成绩 |
| ③ | **Frame API** | 按**时间/公司类型**批量查 | 查**整个年级**某段时间的平均分 |
| ④ | **10-K 原始文件** | 公司交的原版文件（inline XBRL） | 去档案馆**翻原始试卷**，最全 |

> 专业叫法：API = Application Programming Interface（接口），就是"别人给你开的一个查询窗口"。
> 前三个是"整理好的摘要"，第四个是"原始文件"。

**重点：这四样东西看到的"数据详细程度"不一样。**
- ① ② ③ 是 SEC **整理过**的摘要——方便，但**可能漏东西**；
- ④ 是**原始文件**——最全，但要自己慢慢翻。

---

## 4. 我们之前"错"在哪？（用大白话讲）

我们一直用 **工具①（Company Facts API）** 去取数。它确实方便，但有两个"坑"：

### 坑 A：公司根本没贴某个标签

亚马逊的利润表上有"毛利"这一行（Gross profit），但**亚马逊在报给 SEC 时，没有给这一行单独贴标签**。
就像学生写作业，步骤跳过了，老师只看到"收入"和"成本"，中间的"毛利"没标出来。

→ 所以我们查"毛利标签"（GrossProfit），**哪都查不到**（无论哪个工具都没有）。
→ **只能自己算**：毛利 = 收入 − 成本。（这就是"公式推导"）

### 坑 B：工具①没收全某个标签

亚马逊其实贴了"总负债"的标签（Liabilities），在**原始文件④**里能找到。
但我们用的 **工具①（Company Facts）没收全这个标签**——它只收录了一部分标签，这个漏了。

→ 就像档案馆里原始试卷有这道题，但"查成绩的窗口①"没显示。
→ **解决办法**：要么去翻原始文件④，要么**自己算**：总负债 = 负债和权益合计 − 股东权益。

### 用一张表总结

| 数据 | 工具①有吗 | 原始文件④有吗 | 能自己算吗 |
|---|---|---|---|
| 毛利（GrossProfit） | ❌（只有十几年前旧的） | ❌ 亚马逊没贴标签 | ✅ 收入 − 成本 |
| 总负债（Liabilities） | ❌ 没收全 | ✅ 有 us-gaap:Liabilities | ✅ 负债和权益 − 权益 |

## 5. 网页搜索是干嘛的？—— 最后没办法才用它

如果**贴标签系统里没有**（公司没贴标签）、**也推导不出来**（没有能算的公式），那才轮到**去网上找**。

- 网页搜索 = 去网上（公司官网、财经网站）找文字版财报，人工读出数字。
- **但这里数字的可信度低**：网上的数可能过期、口径不同、甚至是假的。
- 所以网页搜索只能是**最后兜底**，而且找到的数要**标注来源**（哪个网址、什么时候），不能假装是 SEC 官方数。

> 类比：标签系统查不到，公式也算不出，那就只能去外面打听——但打听到的信息要标"来源是听说的"，不能当成官方档案。

---

## 6. 那正确的"三步走"是什么？（大白话）

遇到取不到的数字，按顺序试：

```
第一步：自己算（公式推导）
   毛利 = 收入 − 成本  ✅ 确定性，最可靠
   总负债 = 负债和权益 − 权益

第二步：翻原始文件（10-K 的 XBRL）
   标签系统①漏了的，原始文件④里可能有

第三步：上网查（网页搜索）
   前两步都没有，才上网；找到的数标来源、降可信度
```

**每一步都比下一步可靠**——所以从最可靠的开始。

## 7. 专业词汇小抄（遇到不懂就回来看）

| 词 | 大白话 |
|---|---|
| **XBRL** | 给财报数字贴标签的规则系统 |
| **标签 / concept** | 贴在数字上的名字，如"收入""毛利" |
| **SEC** | 美国证监会，公司交财报的档案馆 |
| **API / 接口** | 档案馆开的"查询窗口" |
| **Company Facts API** | 查一家公司所有标签的窗口（我们主要用的） |
| **Company Concepts API** | 查单个标签的窗口 |
| **Frame API** | 按时间批量查的窗口 |
| **10-K** | 公司每年交的"年度财报"（最详细） |
| **inline XBRL / source.html** | 10-K 里贴好标签的原始文件（我们已下载） |
| **命名空间 / us-gaap** | 标签的分组（美国会计准则组的标签） |
| **毛利 GrossProfit** | 收入 − 卖东西的成本 |
| **总负债 Liabilities** | 欠别人的钱（负债和权益 − 股东自己的钱） |
| **勾稽关系** | 财报里"几个数加减能推出另一个数"的固定关系 |
